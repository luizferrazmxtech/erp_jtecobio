{% icone "ajuda" %} Como cada custo é calculado

Os números net são sem os impostos que a JT recupera como crédito (ICMS, PIS e COFINS), do mesmo jeito que a planilha DRE calcula. Os números brutos são os valores da nota, com impostos.

Preço net de venda
{% if pedido.exportacao %}Exportação não tem ICMS, PIS nem COFINS: o preço net é o próprio preço, R$ {{ pedido.preco_unitario|num:4 }}.{% else %} Preço × (1 − ICMS {{ explica.icms_venda|num:0 }}%) × (1 − PIS 1,65% − COFINS 7,6%) = R$ {{ pedido.preco_unitario|num:4 }} × {{ pedido.fator_venda|num:5 }} = R$ {{ explica.preco_net|num:4 }}/kg.{% endif %}
Produto net
Custo do produto no tanque × (1 − ICMS {{ explica.icms_compra|num:0 }}% da compra) × (1 − 9,25% de PIS/COFINS) = custo × {{ pedido.fator_compra|num:4 }}. {% if e %}No {{ e.nome }}: R$ {{ e.custo|num:4 }} × {{ pedido.fator_compra|num:4 }} = R$ {{ e.custo_net|num:4 }}/kg.{% endif %} O custo do tanque é o custo médio do que entrou nele (preço da nota de compra).
Frete net
Frete por kg × 0,88, porque o CT-e dá crédito de 12% de ICMS (o frete não tem PIS/COFINS na conta da planilha). {% if e and e.frete is not None %}No {{ e.nome }}: R$ {{ e.frete|num:4 }} × 0,88 = R$ {{ e.frete_net|num:4 }}/kg.{% endif %} O frete vem da tabela de frete (Vendas → Fretes) e pode ser mudado no cartão do tanque. Sem tabela, o frete conta como zero e o custo médio aparece com *.
Custo efetivo do tanque
Produto + frete. {% if e and e.efetivo is not None %}No {{ e.nome }}: R$ {{ e.custo|num:4 }} + R$ {{ e.frete|num:4 }} = R$ {{ e.efetivo|num:4 }} bruto, e R$ {{ e.custo_net|num:4 }} + R$ {{ e.frete_net|num:4 }} = R$ {{ e.efetivo_net|num:4 }}/kg net.{% endif %} A rota sugerida começa pelo tanque de menor custo efetivo net.
Margem por kg
Preço − custo efetivo. A bruta usa os valores da nota; a net usa os valores sem impostos e é o que a JT ganha de verdade. {% if e and e.margem_net is not None %}No {{ e.nome }}: bruta R$ {{ pedido.preco_unitario|num:4 }} − R$ {{ e.efetivo|num:4 }} = R$ {{ e.margem|num:4 }}; net R$ {{ explica.preco_net|num:4 }} − R$ {{ e.efetivo_net|num:4 }} = R$ {{ e.margem_net|num:4 }}/kg.{% endif %}
Por que a net pode ser menor que a bruta
A diferença é o imposto que a JT ainda tem de pagar: o imposto da venda menos os créditos da compra e do frete. {% if e and e.margem_net is not None %}No {{ e.nome }}: imposto da venda R$ {{ e.imposto_venda|num:4 }} − créditos R$ {{ e.creditos|num:4 }} = R$ {{ e.imposto_pagar|num:4 }}/kg a pagar, e R$ {{ e.margem|num:4 }} − R$ {{ e.imposto_pagar|num:4 }} = R$ {{ e.margem_net|num:4 }}.{% endif %} {% if not pedido.exportacao %}Isso acontece porque a venda paga ICMS de {{ explica.icms_venda|num:0 }}% e PIS/COFINS sobre um preço maior, enquanto o crédito vem de uma compra mais barata (ICMS de {{ explica.icms_compra|num:0 }}%). Se a net ficar maior que a bruta, os créditos superam o imposto da venda.{% endif %}
Custo efetivo médio
Média dos tanques escolhidos, pesada pelos quilos: soma de (kg que sai × custo efetivo) ÷ kg alocados.
Margem net
Receita net − custo net = kg × preço net − soma de (kg × custo efetivo net). A margem bruta faz a mesma conta com os valores da nota; a diferença entre as duas é o imposto a pagar.
